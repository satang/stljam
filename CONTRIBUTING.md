# Contributing

Use Node.js 24 or newer. Run `npm test` before submitting a change. For viewer changes, also run `npm start` and `npm run demo`, then verify the affected interaction in a WebGL browser.

When reporting a bug, include the StlJam version, Node.js version, operating system, and browser. For geometry or export issues, specify the file format and units and attach a small model only if you have permission to share it. The synthetic gearbox demo is a useful starting point for reproductions.

Keep source CAD files, private models, databases, and local review screenshots out of pull requests. Changes to an annotation format or review lifecycle should preserve historical batches and comments.
