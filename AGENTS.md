# StlJam contributor instructions

## Review usability and design for UI changes

Whenever a feature, fix, or other development change affects the interface, review usability and visual design before calling the work complete. Run the app and walk through the affected flow in a browser with representative data.

- Check that the next action is easy to find, labels explain what happens, and primary, secondary, and destructive actions have a clear hierarchy.
- Inspect spacing, alignment, button widths, icons, text wrapping, and contrast in the actual layout. Check a narrow viewport as well as the standard desktop layout.
- Exercise the relevant empty, active, and completed states, plus keyboard or touch interaction where applicable. Review a screenshot or inspect the rendered page directly. Fix usability and design issues found in the affected flow and report what you verified.
